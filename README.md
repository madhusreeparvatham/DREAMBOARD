# ✨ Dreamboard

An interactive digital vision board web app designed to help users organize life goals, pin visual inspiration, and track personal milestones in an aesthetic workspace.

## 🚀 Features
- **Custom Vision Boards:** Create and organize personalized boards for different life categories.
- **Visual Pinning:** Add inspiring images, quotes, and daily affirmations.
- **Goal Tracking:** Turn visual inspiration into actionable milestones.
- **Responsive Design:** Smooth, clutter-free experience across desktop and mobile devices.

## 🛠️ Tech Stack
- **Frontend:** React, Vite
- **Styling:** Tailwind CSS
- **Code Quality:** ESLint

## 💻 Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com
   ```
2. Navigate to the project folder:
   ```bash
   cd DREAMBOARD
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```
